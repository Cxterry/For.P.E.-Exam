\begin{array}{l} 图片中第（3）问的相频特性曲线，主要是通过**几何矢量法（零极点法）**结合**特殊点取值**画出来的。

标准的相频特性公式是：\(\varphi(\omega) = \text{分子相位} - \text{分母相位}\)。

对于系统函数 \(H(e^{j\omega}) = \frac{(e^{j\omega})^2}{(e^{j\omega} - \frac{1}{2})(e^{j\omega} + \frac{1}{4})}\)，我们可以拆解为：

\[
 \varphi(\omega) = \angle(e^{j\omega})^2 - \angle(e^{j\omega} - \frac{1}{2}) - \angle(e^{j\omega} + \frac{1}{4}) 
\]
即：
\[
 \varphi(\omega) = 2\omega - \angle(\text{极点1向量}) - \angle(\text{极点2向量}) 
\]

### 如何具体算出这三点并画出草图？

**1. 代数/几何分析：**
在Z平面上，\(z=e^{j\omega}\) 代表沿单位圆逆时针转动。
*   **分子 \((e^{j\omega})^2\)：** 相位是线性增加的，为 \(2\omega\)。
*   **极点1 \((e^{j\omega} - \frac{1}{2})\)：** 在图上是从点 \((\frac{1}{2}, 0)\) 指向单位圆上一点的向量。
*   **极点2 \((e^{j\omega} + \frac{1}{4})\)：** 在图上是从点 \((-\frac{1}{4}, 0)\) 指向单位圆上一点的向量。

**2. 代入三个关键点（与图片完全对应）：**

*   **当 \(\omega=0\) 时（点在(1,0)）：**
    *   分子相位 \(2\times 0 = 0\)
    *   极点1向量 \(1 - 0.5 = 0.5\)，实轴正方向，相位为 \(0\)。
    *   极点2向量 \(1 + 0.25 = 1.25\)，实轴正方向，相位为 \(0\)。
    *   \(\varphi(0) = 0 - 0 - 0 = 0\)。

*   **当 \(\omega=\frac{\pi}{2}\) 时（点在(0,1)）：**
    *   分子相位 \(2 \times \frac{\pi}{2} = \pi\) (\(180^\circ\))
    *   极点1向量：\((0,1) - (0.5,0) = (-0.5, 1)\)。该向量在第二象限，角度约为 \(116.6^\circ\)。
    *   极点2向量：\((0,1) - (-0.25,0) = (0.25, 1)\)。该向量在第一象限，角度约为 \(76^\circ\)。
    *   总相位：\(180^\circ - 116.6^\circ - 76^\circ \approx -12.6^\circ\)。
    *   所以得到 \(\varphi(\frac{\pi}{2}) < 0\)（为负值）。

*   **当 \(\omega=\pi\) 时（点在(-1,0)）：**
    *   分子相位 \(2 \times \pi = 2\pi\)（相当于 \(0\)）。
    *   极点1向量：\((-1,0) - (0.5,0) = (-1.5, 0)\)。实轴负方向，相位为 \(\pi\)。
    *   极点2向量：\((-1,0) - (-0.25,0) = (-0.75, 0)\)。实轴负方向，相位为 \(\pi\)。
    *   总相位：\(2\pi - \pi - \pi = 0\)。

### 总结：
因为 \(\varphi(0)=0\)，\(\varphi(\pi/2)\) 为负数，且 \(\varphi(\pi)=0\)，又因为分子项 \(2\omega\) 是向上拉，而两个分母项在 \(\frac{\pi}{2}\) 处拉得更厉害，所以总相位在 \(0\) 到 \(\pi\) 之间会先下降到谷底（负值），然后再上升回到 \(0\)。这就是你在图片底部看到的“先向下凹，再回升”的波浪形曲线的由来。

*注：如果要写出相频特性的**精确解析表达式**，可以直接写为：*
\[
 \varphi(\omega) = 2\omega - \arctan\left(\frac{\sin\omega}{\cos\omega - \frac{1}{2}}\right) - \arctan\left(\frac{\sin\omega}{\cos\omega + \frac{1}{4}}\right) 
\]
但在考试中，通常不需要写出这个复杂的式子，只需根据零极点图画出定性草图即可。\end{array}
